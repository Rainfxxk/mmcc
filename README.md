# Mini Mini Claude Code

`mmcc`(Mini Mini Claude Code) is an extremely simplified implementation of Claude Code — built for learning, hacking, and experimenting.

## ✨ Features


|feature|support|
|:------|:------|
|loop|✅|
|context|❌|
|tool|❌|
|context compact|❌|
|subagent|❌|
|skill|❌|


## ⚙️Configuration

Set the following environment variables in your shell, or add them to your .bashrc:

```shell
export MINI_MINI_CLAUDE_API_KEY=[your-api-key]
export MINI_MINI_CLAUDE_BASE_URL=[your-api-base-url]
export MINI_MINI_CLAUDE_MODEL_NAME=[your-model-name]
```

## 🚀 How to Run

Make sure uv is installed on your system.

```shell
git clone <repo-url>
cd mmcc

uv sync
uv run mmcc
```
